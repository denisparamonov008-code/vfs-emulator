# Эмулятор UNIX-оболочки

Вариант 26. Этап 1: минимальный прототип REPL.

Приглашение содержит имя VFS. Парсер раскрывает переменные
окружения реальной ОС (например, `$HOME`). Команды `ls` и `cd`
пока заглушки: выводят свое имя и аргументы.

## Запуск

```text
python3 src/emulator.py
```

## Команды

- `ls [аргументы...]` - заглушка, печатает имя и аргументы;
- `cd [аргументы...]` - заглушка, печатает имя и аргументы;
- `help` - справка;
- `exit` - выход.

Ошибки: неизвестная команда, неверные аргументы, ошибка разбора.

## Скрипты запуска

- `run.sh` - Linux/macOS;
- `run.bat` - Windows cmd;
- `run.ps1` - PowerShell.
