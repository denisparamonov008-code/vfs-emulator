# Эмулятор UNIX-оболочки

Вариант 26. Реализованы этапы 1, 2 и 3.

## Запуск

```text
python src/emulator.py --vfs vfs.csv
python src/emulator.py --vfs vfs.csv --script scripts/startup_commands.txt
```

## Команды

- `ls [путь]` - список элементов виртуального каталога;
- `cd [каталог]` - переход по VFS;
- `help` - справка;
- `conf-dump` - параметры запуска;
- `exit` - выход.

## Этап 3. VFS

Виртуальная файловая система хранится в CSV и при запуске полностью загружается в память. После загрузки команды `ls` и `cd` работают с объектом VFS, не изменяя файлы VFS и не выполняя файловые операции хостовой ОС для содержимого виртуальной файловой системы.

CSV имеет поля `type,path,content,encoding`. Для обычного текста используется `plain`, для двоичных данных предусмотрен `base64`. Вложенные каталоги задаются обычными путями, например `/home/student/projects/vfs/src/demo`.

Если в корне VFS существует файл `/motd`, его содержимое выводится при запуске эмулятора.

Для проверки этапа 3 подготовлены варианты VFS:

- `vfs-min.csv` - минимальная VFS;
- `vfs-files.csv` - VFS с несколькими файлами;
- `vfs-deep.csv` - VFS с несколькими уровнями каталогов.

Скрипты реальной ОС `scripts/test_min.*`, `scripts/test_files.*` и `scripts/test_deep.*` запускают эмулятор с соответствующим вариантом VFS. Файлы `test_*_commands.txt` задают команды, которые эмулятор выполняет в тестовом режиме.

## Стартовый скрипт

`scripts/startup_commands.txt` содержит комментарии, обычные команды и примеры обработки ошибок. Эмулятор пропускает пустые строки и строки, начинающиеся с `#`.
