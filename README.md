# Эмулятор UNIX-оболочки

Вариант 26. Этап 2: настраиваемый эмулятор.

Приглашение содержит имя VFS. Парсер раскрывает переменные
окружения реальной ОС (например, `$HOME`). Команды `ls` и `cd`
пока заглушки: выводят свое имя и аргументы.

## Запуск

```text
python3 src/emulator.py --vfs vfs.csv
python3 src/emulator.py --vfs vfs.csv --script scripts/startup_commands.txt
```

При запуске эмулятор печатает заданные параметры (отладочный вывод).

## Команды

- `ls [аргументы...]` - заглушка, печатает имя и аргументы;
- `cd [аргументы...]` - заглушка, печатает имя и аргументы;
- `help` - справка;
- `conf-dump` - параметры запуска в формате ключ=значение;
- `exit` - выход.

Ошибки: неизвестная команда, неверные аргументы, ошибка разбора,
ошибка исполнения стартового скрипта.

## Стартовый скрипт

`scripts/startup_commands.txt` содержит комментарии, обычные команды
и примеры обработки ошибок. Эмулятор пропускает пустые строки
и строки, начинающиеся с `#`. При выполнении на экране видны и ввод,
и вывод, имитируя диалог с пользователем.

## Скрипты запуска

- `run.sh` - Linux/macOS;
- `run.bat` - Windows cmd;
- `run.ps1` - PowerShell.
